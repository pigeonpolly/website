# Календарь 2027 «Небо и земля» (A3, печать)

Утверждённый Алиной вариант (16.11.2026): арт «Козий город» на весь лист; сверху тёмное небо-глазурь с январём–июнем и «2027» (над флюгером — мягкий светлый полукруг), снизу тёмная «земля» с июлем–декабрём, внизу мелко `pigeonpolly.com`. Названия месяцев — сиреневые `#c9c4ea` (Caveat Brush), даты и дни недели — Patrick Hand, выходные `#ffb47e`. Неделя с понедельника, 6-я неделя — в пустые клетки первой.

    python3 tools/print/cal2027/build.py СКАН.tif --out папка

- Скан — весь лист на светлом фоне: край и наклон ищутся сами (`check_sheet.jpg` — проверить кадр), иначе `--crop x0,y0,x1,y1 --rot град`; уже обрезанный арт — `--nocrop`.
- Цвета «сочнее и чётче» — `enhance.py` (`--vib`, по умолчанию 0.30).
- Выход: `Calendar_2027_A3_RGB_bleed3mm.pdf`, `Calendar_2027_A3_RGB.pdf`, `Calendar_2027_A3_CMYK_bleed3mm.pdf` (ISO Coated v2 300 % / FOGRA39), `Calendar_2027_30x42_minnti.jpg` (sRGB, Minnti берёт только картинку 30×42), превью.
- Первая версия была с фото iPhone (6048×8064, лист выпрямлен по краям); скан даёт лучшее качество.
- Скан Epson 600 dpi (16.11.2026, PDF с одной JPG-картинкой, лист боком): повёрнут на 0,87°, вырезан x 10203–20084, повёрнут на 90° против часовой, затем `--nocrop --vib 0.15 --vscale 0.978` (скан и так сочный; сжатие по высоте на 2 %, чтобы кружка внизу была над полосой).
