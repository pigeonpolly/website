# A1 English Lab — курс английского A1 для взрослых

На каждую тему — **два файла**, каждый открывается двойным кликом в браузере (всё внутри, работает без интернета, кроме видео):

| Файл | Что внутри |
|---|---|
| `<тема>-prezentacija.html` | слайды для урока с интерактивами: карточки слов с озвучкой, переключатель «+ − ?», квизы по клику, сборка фраз, случайный вопрос, таймер. Клавиши: ←/→, F — весь экран, N — заметки преподавателя, O — обзор, A — ответ |
| `<тема>-tema.html` | учебник темы: история Оскара перепиской, правило, слова с озвучкой, 7 упражнений с проверкой (XP, конфетти, реакции Оскара), факты о Британии, видео, частые ошибки, тест. В конце — домашка: «Скачать выполненное (PDF)» с именем, датой и автопроверкой |

Пример: `topics/to-be/`. Оскар — британский кот, гид в Лондоне (`OSKARS.md`).

## С ИИ
Скилл `/a1-pack`: спросит тему, цвет, длительность — соберёт оба файла.

## Без ИИ
Текст темы — в `topics/<тема>/topic.json` (формат — `SCHEMA.md`). Поменять текст и выполнить
`python3 a1-pack/tools/build_lab.py a1-pack/topics/<тема>`.
