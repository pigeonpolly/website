# A1 English Pack — шаблоны курса английского A1

Дизайн: швейцарский минимализм, белый + чёрный + один цвет темы, тонкие серые линии, кот Оскар (британец, гид в Лондоне — `OSKARS.md`).
Шрифты с латышскими буквами: **Nunito** (заголовки), **Inter** (текст), **Caveat** (рукописные пометки) — лежат в `fonts/`.

## Что в паке темы
| Файл | Что | Форматы |
|---|---|---|
| prezentacija | слайды 16:9, заметки для преподавателя | HTML (F — показ, A — ответ), PDF, PPTX |
| majasdarbs | домашка: имя/дата, напоминание об ошибках, 4–5 упражнений, «Сохранить PDF» | HTML, PDF, DOCX |
| pasparbaude | тесты по клику, Kļūdu detektīvs, факты с Оскаром, видео | HTML, PDF, DOCX |
| atbildes | мастер-PDF со всеми ответами | HTML, PDF, DOCX |
| metodika | цели, can-do CEFR A1, план по минутам, советы | HTML, PDF, DOCX |
| rezerves | 3–4 запасных активных задания | HTML, PDF, DOCX |
| kludas | частые ошибки носителей латышского | HTML, PDF, DOCX |

## С ИИ
Скилл `/a1-pack` (`.claude/skills/a1-pack/SKILL.md`): спросит тему, цвет, длительность, нужные материалы — и соберёт `topics/<тема>/<тема>-pack.zip`.

## Без ИИ — вручную
1. Установить шрифты из `fonts/` (двойной клик → «Установить»), иначе Word/PowerPoint подставят похожие.
2. Взять пустые шаблоны из `veidnes/` (Word и PowerPoint, все типы слайдов и упражнений), заменить текст в [скобках].
3. Цвет темы: в PowerPoint — «Формат → Заливка» у полоски внизу слайда и цветных надписей; в Word — цветные цифры заголовков.
4. Готовый пример — `topics/to-be/to-be-pack.zip`.

Тем, кто умеет запускать Python: поправить `topics/<тема>/topic.json` по `SCHEMA.md` и выполнить
`python3 a1-pack/tools/build_pack.py a1-pack/topics/<тема>` — пересоберёт все форматы.
