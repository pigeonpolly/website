# Новость о сайте → черновик в блоге

Доступа к D1 нет, поэтому черновик кладётся файлом: `site/assets/blog-drafts.json`. Worker (`importDrafts` в worker/blog.js) при первом обращении к блогу добавляет каждую новую статью из файла в «Черновики» редактора — один раз (метка meta `blog_draft:<slug>`), потом её правит только Алина. Удалять старые записи из файла не нужно, менять уже добавленные — бесполезно (не перезапишутся): для исправлений — новый `slug`.

## 1. Факты
- Темы — от Алины. Факты брать только из docs/plan-status.md и docs/*.md (через `tools/sec.py`), числа — из RULE_DEFAULTS (worker/index.js, worker/<игра>.js). Ничего не придумывать; неясное — спросить.
- Адреса страниц и названия — как на сайте (RU-версия в src/pages/*.ru.html или словари в JS).

## 2. Картинки — без текста
Алина переводит статьи сама, поэтому на картинке **не должно быть надписей**: только сама сцена (canvas), без подписей, кнопок, всплывающих подсказок, окон с текстом.
- `python3 -m http.server 8790 --directory site &` (сначала `python3 build.py`, если site/ устарел).
- `node tools/news_shots.js <room|garden|wl|shift|hol|all>` — снимки в `_shots/news/`, /api подменяется данными-примерами прямо в скрипте. Для новой сцены — добавить блок по образцу: снимать элемент `canvas`, HTML поверх прятать (`addStyleTag` с `visibility:hidden`/`opacity:0`), мышь уводить (`mouse.move(0,0)`), чтобы не было подсказки.
- Посмотреть каждый снимок (Read). Есть текст — переснять/обрезать.
- В webp: `python3 -c "from PIL import Image; im=Image.open('_shots/news/c-x.png').convert('RGB'); im.save('site/images/blog/<папка>/x.webp','WEBP',quality=88)"` — папка `site/images/blog/site-news-<гггг-мм>/`, шире 1200 — уменьшить (`Image.NEAREST`, пиксель-арт).

## 3. Текст
- По-русски, тёплым тоном сайта, на «ты» к читателю, **без рода** («сама прибегает в открытую комнату», не «ты открыл»).
- Структура: вступление 1–2 фразы → по разделу `<h2>` на тему → 1–3 абзаца + картинка → короткое приглашение в конце.
- HTML только из разрешённого (ALLOWED в worker/blog.js): p, h2, h3, b, i, ul/ol/li, a, figure/img/figcaption. Картинка: `<figure><img src="/images/blog/…webp" alt="подпись"><figcaption>подпись</figcaption></figure>`.

## 4. Запись в файл
Добавить объект в `posts` файла `site/assets/blog-drafts.json` (питоном, `json.dump(..., ensure_ascii=False, indent=1)`):
`slug` (латиница, уникальный), `cover` (одна из картинок), `t_ru`, `d_ru` (1 фраза), `b_ru`, `tags_en` (через запятую, по-английски), `section: "stories"` (Новости сайта), `src_lang: "ru"`. EN/LV не писать — Алина переведёт в редакторе.

## 5. Проверка и пуш
- `node --check worker/blog.js`, `python3 build.py`.
- Строка в docs/plan-status.md, коммит, пуш в `main`.
- Алине (≤5 строк): тема статьи, что она в «Черновиках» блога (появится после выкладки, при первом открытии блога), раздел «Новости сайта».
