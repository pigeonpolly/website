# Набор пинов-тизеров → /draw/ → Notion

Образец — 20.11.2026, №945–1084 (`utm_campaign=top26`), docs/palettes.md → Pinterest.

## Правила Алины
- **Пин не отдаёт всё сразу** (20.11): видно начало (неделя тем, цвета без HEX, 3 шага из 4, головоломка без ответов, контур с затуханием), полное — на сайте `/draw/?f=p<номер>`. На пине — кнопка-призыв «Get all 31 prompts», «See step 4 on my site»…
- Тема — v2 сайта (TH в tools/pins/pins16.js), значок v3 по фону: светлый → color-autumn, тёмный/ночной → color-winter, мятный → spring, летний → summer.
- Темы не повторять: проверить заголовки прошлых пинов — `cat tools/pins/*.json | grep -o '"title": "[^"]*"'`. Преобладают самые заходящие форматы по свежей аналитике (Алина присылает CSV с Диска: «Top boards», «Top pins»).
- Только её арты (site/images/bird, snail, sketchbook, halloween, anxiety, photos2). AI-арт не брать. Всё на английском.

## Шаги
1. Данные — новый файл `tools/pins/pins<SET>-data.js` (копия pins16-data.js): массивы PR (темы), PA (палитры: кадр детали [x,y,w,h] в долях), ST (шаги), PCH, BG, ISPY, DF, DT. Номера — следующий свободный (docs/palettes.md). Ссылка — `L(_, n)` → /draw/.
2. `SET=<SET> python3 tools/pins/pins16_prep.py all` → tools/pins/p16/ (не в git): шаги (карандаш → тушь → заливка → готово), контуры, отличия, кадры и палитры (алгоритм tools/palettes.py).
3. `SET=<SET> node tools/pins/pins16.js` → site/images/pins/pin-NNN.jpg, tools/pins/pins<SET>.json, site/images/draw/, дописывает site/assets/draw.json (старые наборы остаются).
4. Посмотреть листом (8 в ряд по 250 px): кадры палитр и превью тем — по сюжету, текст не наезжает на подвал (движок пишет ⚠).
5. `python3 build.py`, проверить /draw/ и `/draw/?f=p<номер>` на 390 и 1440 (3 языка), что окна открываются.
6. Notion «Pinterest pins 3.0» (`collection://5d16a77b-7199-4a1c-a3b2-07d17f217de3`): №, Заголовок, Ссылка, Шаблон (Темы/Палитра/Процесс/Арт), Язык EN, Актуальность (сезон), внутри — картинка, Description, Alt, Topics. Пачками по 35.
7. Строка в docs/palettes.md и plan-status, коммит, пуш.
