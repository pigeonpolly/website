# Набор пинов по заходящим темам → настоящие страницы сайта → Notion

Образец — 21.11.2026, №1085–1308 (`utm_campaign=top27`, адвент — `advent26`), docs/palettes.md → Pinterest.

## Правила Алины
- **/draw/ убрана** (docs/retired.md) — пины ведут на настоящие страницы: темы → `/prompts/`, палитры → `/palettes/#ключ`, игры → `/games/`, адвент → `/advent/`.
- **Аналоги залетевших — открытые** (21.11): список тем на месяц виден целиком (сохраняют себе), палитры — разного формата и числа цветов, HEX видны. Тизер («остальное на сайте») — только там, где полное правда есть на сайте (настоящий список месяца на /prompts/).
- Новые палитры — серией на сайт (`content/palette-details.json` + `tools/palettes.py`), чтобы ссылка вела на ту же палитру.
- **Никогда не делать пины «How to paint … in 4 steps»** (Алина 28.11: «вот такие вообще никогда больше не делай», «сам концепт не нравится») — ни сгенерированные шаги из арта, ни сам формат «как нарисовать по шагам»; docs/retired.md.
- **Палитры — 6 или 8 цветов** (Алина 28.11: меньше 6 не делать). **Без конкретных дат:** не «тема на 4 декабря», «окно 12», «World … Day», «11.11» — можно праздник целиком, сезон, месяц.
- **Арт не обрезать** (Алина 28.11): рамка по пропорциям арта, горизонтальный — наверху на всю ширину; на арте уже есть текст — свой не добавлять; списки без пустот. Подробно — social-content-factory §4.
- Адвент: что внутри окон — не говорить (подарки можно показать только размытыми «сквозь иней»).
- Тема — v2 сайта (TH в tools/pins/pins17.js), значок v3 подобран к акценту пина (лист сравнения: все варианты v3 на всех фонах).
- Темы не повторять: `cat tools/pins/*.json | grep -o '"title": "[^"]*"'`. Заголовок ≤ 100 знаков.
- Только её арты (site/images/bird, snail, sketchbook, halloween, anxiety, photos2). AI-арт не брать. Всё на английском.

## Шаги
1. Данные — `tools/pins/pins<SET>-data.js` (копия pins17-data.js); настоящие списки месяца — снимок `GET https://www.pigeonpolly.com/api/challenge/month?m=YYYY-MM` в `pins<SET>-months.json`. Номера — следующий свободный (docs/palettes.md).
2. Новые палитры: строки в `content/palette-details.json` (ключ, арт, кадр, названия EN/RU/LV) → `python3 tools/palettes.py`; 8 цветов — `python3 tools/pins/pins17_pal.py`.
3. Заготовки: `SET=<SET> python3 tools/pins/pins16_prep.py diff` (tools/pins/p16/), адвент — `node tools/pins/pins17_shots.js` при `python3 -m http.server 8799 --directory site`.
4. `node tools/pins/pins17.js [номер…]` → site/images/pins/pin-NNN.jpg + tools/pins/pins17.json (движок пишет ⚠, если текст наезжает на подвал).
5. Лист 10 в ряд по 200 px — посмотреть всё; `python3 build.py`, /palettes/#новый-ключ на 390 и 1440 (3 языка).
6. Notion «Pinterest pins 3.0» (`collection://5d16a77b-7199-4a1c-a3b2-07d17f217de3`): №, Заголовок, Ссылка, Шаблон (Темы/Палитра/Процесс/Арт/Адвент), Язык EN, Актуальность; внутри — картинка, Description, Alt, Topics. Пачками по 32.
7. Строка в docs/palettes.md и plan-status, коммит, пуш.
