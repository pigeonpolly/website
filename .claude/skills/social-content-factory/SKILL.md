Одна картинка (пин 1000×1500) идёт во все три места. Ничего не публикуем сами: всё складываем в Notion, публикует Алина.

## 1. Анкета — до любой генерации, одним списком
Сначала прочитать Drive (что нового в папках, даты файлов) и Notion (последний №), потом спросить:
1. Арты: только новые из «Pin New Images», только старые с сайта или микс — в каком %?
2. Свежая аналитика и лучшие пины Pinterest в папке есть? (назвать, что нашла, с датами)
3. Свежая аналитика и лучшие посты Facebook в папке есть? (так же)
4. % по темам — базовый список (§3) + 3 новые темы, которые предлагаю по аналитике (каждая — одной строкой «почему»). Дать свой черновик %, чтобы Алина просто поправила.
5. Для сезонных/праздничных — какие месяцы? (по умолчанию текущий и следующий)
6. Сколько карточек? (без числа не начинать — число называет Алина)
7. Какая доля карточек с артами про Полли (из её галереи)? (черновик — около 20 %)

Ответы, допущения и итоговый план (№ → тема → арт → доска) записать строкой в docs/plan-status.md до генерации.

## 2. Аналитика → решения
- Pinterest CSV: «Top Boards» (показы, сохранения, **outbound clicks**) и «Top Pins». Ссылки на пины без названий — названия есть на скриншотах. Главное — сохранения и переходы, не показы.
- Facebook: скриншоты «Топовый контент» и охват — какие посты (тема, формат) дали вовлечённость.
- Выводы — 3–5 строк в plan-status: что повторяем, что убираем, откуда 3 новые темы.
- Помнить (docs/growth.md §3): пин, который отдаёт всё, на сайт не ведёт. Тизер — только там, где полное правда лежит на сайте; палитры и списки тем — открытые (сохраняют себе).

## 4. Карточка (визуал)
- 1000×1500, текст **только по-английски**, заголовок ≤ 100 знаков, крупно и читаемо на телефоне.
- **Левый нижний угол** — порядковый № (`#12` или `12`), 18–20 px, цвет текста с прозрачностью ~0.35: еле заметен.
- **Правый нижний угол** — логотип v3 (`site/images/logo/v3/pigeon-polly-<вариант>-transparent-4000.png`), ~90 px, вариант под фон (как `TH.*.logo` в tools/pins/pins17.js: светлый фон → color-autumn/spring/summer/purple, тёмный → color-winter или white-only), рядом мелко `pigeonpolly.com` цветом `mut`. Никаких плашек, кнопок-CTA и ярких подложек: лого и сайт не кричат.
- Год и месяц на карточке — только если без них тема ломается («December prompts» можно, «2027» — нет, если не про цели года).
- Основа — **работы Алины** (site/images/bird, snail, sketchbook, halloween, anxiety, photos2, wobbleland, новые из Drive). Иначе скриншот pigeonpolly.com (Playwright, `tools/shots.py`) или нейтральный фон темы. AI-арт (site/images/ai-art) не брать.
- Новые арты с Drive: HEIC → JPG как в art-pins §1 (`pillow-heif`), повернуть по EXIF, обрезать фон стола, если он мешает. На сайт новые арты не добавлять, если Алина не попросила — для карточек они лежат в `site/images/social/src/`.
- Темы оформления — палитры TH из pins17.js; соседние карточки — разные фоны и раскладки (арт сверху, арт на весь фон с плашкой текста, список в 2 колонки, палитра с плашками HEX, мем — белый верх + арт).
- **Полли — только готовые арты Алины** (галерея `site/images/bird/`, календари и заставки /freebies/, обложки с Полли). Самой Полли не рисовать — ни пиксельной, ни векторной, ни через нейросеть (Алина 27.11: «не получается вообще»). Сюжет карточки подбирать под арт: Полли рисует → «Polly paints by the window», Новый год → «New Year in bed» и т. п.
- Генератор: `tools/pins/scf<ГГММ>.js` (+ `-data.js`) — копия движка tools/pins/pins17.js (Playwright, HTML→JPG), подвал заменить на №+лого из этого раздела. Выход — `site/images/social/card-<№>.jpg` (номер 4 знака: card-0001.jpg) и `tools/pins/scf<ГГММ>.json` со всеми текстами.

## 5. Тексты к каждой карточке (всё по-английски)
- **Pin Title** ≤ 100 знаков, с ключевыми словами (как пишут в поиске Pinterest).
- **Pin Description** 2–4 предложения, ключевые слова естественно, последняя фраза — что найдут по ссылке (только правду).
- **Pin Alt Text** — что на картинке, 1 предложение.
- **Pin Board** — только из существующих вариантов колонки (сейчас 20: Aesthetic Color Palettes, Drawing Prompts & Ideas, Free Printables, Relatable Artist Memes, Cozy Christmas Aesthetic…). Подходящей нет — **не создавать**: собрать предложения новых досок и спросить Алину одним списком, карточке пока ближайшую.
- **Facebook Post Text** — сторителлинг в стиле Алины (docs/growth.md → Facebook EN): крючок первой строкой, живые детали из картинки, поворот, вопрос в конце; 1–2 абзаца, почти без эмодзи, без ссылок (можно «it's on my website»). Картинка — та же карточка, новую не делать.
- **FB group No promotion text** — пост для арт-групп: польза сама по себе (совет, мини-урок, вопрос к художникам, история процесса), без ссылок, без «visit/buy/link in bio», без названия сайта. Цель — чтобы захотелось открыть профиль самим.
- Не повторять крючки и первые строки внутри пачки и с прошлыми (поиск по базе SQL `LIKE`).

## 6. Notion
- Номера: сквозные **в этой базе, с 1**. Следующий = max номера из начала title + 1: `SELECT "Номер пина и его содержимое" FROM "collection://69634395-245b-8362-aa6e-07febe1124f0"` → число до точки. Номер на картинке = номер в Notion.
- Title: `<№>. <коротко по-русски, о чём карточка>` (например `12. Палитра «Зимний трамвай», 5 цветов`).
- Свойства: `Тип` (§3), `Сезон` (Зима/Весна/Лето/Осень/Круглый год), `Праздник` (или «Без привязки к празднику»), все Pin-поля, оба текста FB, галочки `__NO__`.
- Тело страницы — картинка ссылкой прямо в тексте, чтобы сразу было превью (и обложка в доске Notion):
  ```
  ![](https://www.pigeonpolly.com/images/social/card-0012.jpg)
  **№12**
  ### Pin
  ```txt …Title / Description / Alt / Link… ```
  ### Facebook
  ```txt … ```
  ### FB groups
  ```txt … ```
  ```
- Справочники: нужен праздник или тип, которого нет, — добавить вариант в `Праздник` / `Тип` через `notion-update-data-source` в том же стиле: по-русски, коротко, без дат («Хеллоуин», «Новый год и Рождество», «День всех влюблённых»). Существующие варианты не переименовывать и не удалять.
- Создавать **после пуша** (картинки должны открываться): `notion-create-pages` пачками по 25–30; потом SQL-проверка, что число строк и номера сходятся.
