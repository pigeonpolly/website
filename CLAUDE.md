# pigeonpolly.com — правила для Claude

Сайт Алины Откинской (Pigeon Polly Art Lab): художница, иллюстратор, learning experience designer из Риги. https://www.pigeonpolly.com (EN), /lv/, /ru/.

## Как общаться с Алиной
- По-русски, до 5 строк, без технических подробностей, кода и пересказа плана. Вопросы — одним списком; не блокирующее решать самой и писать в «Допущения».
- Дизайн показывать скриншотами, не словами. Факты о ней не придумывать — спросить или взять из `content/`.
- Она правит только через Claude: собрать, проверить, закоммитить, запушить в `main`.

## Как выполнять этап
- **Начало.** docs/plan-status.md, потом только разделы из строки «Читай» — через tools/sec.py, docs/map.md, для базы — docs/db.md. history.md — только если что-то не сходится. Перед работой — «Общее» в map.md, готовое заново не делать; новые общие модули — строкой туда же.
- **Части.** Есть «Сессии:» и Алина написала «Часть X» — только её. В конце: строка в plan-status, коммит, пуш и Алине: «Часть X готова. Новая сессия: вставь блок и сверху „Часть Y“».
- **«Продолжи»** — по plan-status с первого несделанного пункта.
- **Перед вопросом или листом Алине** — записать в plan-status, что сделано и что дальше.
- **Большие файлы** (worker/index.js, worker/blog.js, room.js, birds.js, sketch-wall.js, flock.js, admin.js, style.css…) целиком не читать: `grep -n` → ±40 строк. Explore — только если 2–3 grep не нашли.
- **Правки** — точечно (Edit), целиком не переписывать. Данные из deny (.claude/settings.json) — только python3 -c / node -e.
- **Тексты.** Шаблоны src/ — через tools/i18n_add.py, сразу 3 языка. В JS — en/ru/lv рядом с кодом, не в словари. RU — без рода.
- **Вывод** — `| tail -20`; изменения — `git diff --stat`.
- **Проверка.** Сначала `tools/shots.py --check`. Картинки в конце: изменённое место, 390 и 1440; смотреть только общий лист. Алине — не больше 2 листов за этап и 2 кругов правок на лист.
- **Сборка** `python3 build.py` и полная проверка — один раз перед пушем.
- **Живой сайт.** Доступа к D1/R2 и Gemini нет: данные — файлом в site/assets/ или site/images/, worker импортирует сам по метке в meta (как sections_v2) или по кнопке в кабинете.
- **Числа механик** — в «📜 Правилах» (RULE_DEFAULTS, cleanRules, «Тонкая настройка»).
- **Границы** — только блок этапа; «Не трогать» не трогать.
- **Конец этапа:** 3–5 строк в нужный docs/*.md, новые таблицы — в db.md, строка в plan-status, коммит, пуш.
