# «Конвертик» (новости птички) и адвент на главной — этап 4

## Конвертик (4 А)

* Одна очередь новостей: сервер `NEWS_KINDS` в worker/index.js → `news: [{kind, n, …}]` в `/api/whoami` и `GET /api/news`; клиент — site/assets/news.js (`KINDS`, `window.PPNews.refresh()`).
* **Новый вид новости = одна запись в `NEWS_KINDS` и одна в `KINDS`** (icon, title, text, act — подпись кнопки, go — ссылка или open — действие в ленте).
* Виды сейчас:
  * `gift` — неоткрытые подарки (gifts status 'new') → «Открыть подарок» → `/bird/#gift` (sketch-wall.js сразу открывает подарок);
  * `salary` — неоткрытая зарплата (button_log 'salary', seen = 0) → «Открыть конвертик»: письмо открывается прямо в карточке (бывшее окно #acct-sal, анимация CSS `.sal-*`), POST /api/salary/seen;
  * `advent` — 1–31 декабря, пока сегодняшнее окошко не открыто: «Окошко №N открылось!» или «Тебя ждут N окошек» → `/advent/#d=N`; после открытия в этот день не показывается;
  * `potion` — ингредиенты от друзей (potion_gifts seen = 0) → «Посмотреть» → /potions/.
  * `reply` (ответ на комментарий) пропущен: у комментариев блога пока нет ответов.
* 🔔 в шапке — `#pp-bell` (src/layout.html), видна вошедшим с ником, число — сколько карточек. На узкой шапке (c1–c3) — без рамки.
* Есть новое — на каждой странице из правого нижнего угла вылетает пиксельный конвертик «У тебя N новостей!» (ждёт, пока закроют другое окно; после перехода из ленты — не вылетает). «Потом» — прячет до следующей страницы.

## Адвент: даты и блок на главной (4 Б)

* Окошки открываются сами по дате (Рига): /api/advent отдаёт `nextAt` (следующая полночь по Риге) и `date`; advent.js и блок на главной в полночь спрашивают сервер заново. `/advent/#d=N` — прокрутить к окошку N и открыть его.
* Проверка дат локально (DEV_FAKE_LOGIN): `?devdate=2026-11-30T23:59:50` (время по Риге, можно без времени) — account.js запоминает на вкладку (`PPDevH`), часы идут дальше, шлёт `x-dev-date` из всех страниц; `?devdate=off` — забыть. Проверено: 30.11 23:59 → 1.12 00:00, 24.12, 31.12, 1.01, 23.01, 24.01.
* src/blocks/season.html (на главной под приветствием): 1.10–30.11 — домик-календарь и отсчёт до `startsAt`; 1–31.12 — окошко дня / «открыто ✓ · следующее через», пропущенные; 1–23.01 — «Ещё можно забрать пропущенные»; 24.01–30.09 — блок пустой. Гостю — «Вылупи птичку, чтобы открывать окошки».
* «🤖 Автопилот»: с 15 ноября до конца декабря строка «Адвент: заполнено N из 31 окошек» — жёлтая (`warn`), если меньше 31.
