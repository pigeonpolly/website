# Коллекционные карточки

## ТЗ (этап 2)

Коллекционные карточки за пуговки, в магазине /shop/ — раздел «🃏 Карточки».
Каждая карточка существует в ОДНОМ экземпляре на весь сайт. Купленная остаётся в магазине, но серой; вместо «Купить» — ник владельца со ссылкой /bird/?nick=.

Редкость:

* обычная 🤖 — нарисована ИИ, пометка робота. Цена = средняя «цена сейчас» обычной вещи × множитель (по умолчанию 100 %), округление до 5. В кабинете — только множитель.
* редкая — пиксель-арт Алины, пометка «нарисовала Алина»; цену ставит Алина.
* уникальная — акварель Алины, пометка «нарисовала Алина»; цену ставит Алина.

Поля:

* номер (уникален; новая = следующий; смена на занятый — карточки меняются номерами);
* название, описание;
* статы: 3 строки «название: 1–10»;
* коллекция, редкость, цена, картинка, скрыта.

Языки: текст пишется на одном языке → автоперевод Gemini (общая функция) → можно поправить. На сайте — на языке страницы.
Картинка 5:7.

* Обычные — пиксель-арт 120×168, показ с image-rendering: pixelated.
* Рамка, номер и пометка — CSS, не в картинке.
* Карточки Алины — загрузка в кабинете → R2 cards/.
* Карточки из репозитория — site/images/cards/<коллекция>/NN.png.

Окно карточки (магазин, альбом): карточка крупно, справа название, описание, статы, номер, редкость, владелец. На телефоне — под картинкой.

Владелец не может удалить, подарить или продать карточку, только обменять. Обмен — ровно 5 схем:

* обычная↔обычная, редкая↔редкая, уникальная↔уникальная (1 к 1);
* 5 обычных ↔ 1 редкая;
* 10 обычных ↔ 1 уникальная.

Один обмен = одна схема.

Удалила аккаунт — карточки снова свободны. Блокировка их не трогает. Карточки входят в «Мои данные».

Альбом (этап 7): в каждой комнате есть furn|album. Его нет в магазине, его нельзя продать, подарить, убрать в сумку или в коробку. Двигается как мебель. Нажатие — альбом с бесконечными страницами: сначала уникальные, потом редкие, потом обычные (по номеру). Гости тоже могут смотреть.

Админ может удалить карточку, только если у неё нет владельца; иначе — только скрыть.

Правило в «📜 Правилах»: «карточек одной коллекции в одни руки в первые сутки» (0 — без лимита, по умолчанию 0).

## Как устроено (этап 2 А)

- **База** (worker/cards.js, таблицы создаёт `ensureSchema`): `cards` (номер `n` уникален, тексты `t_/d_` на en/ru/lv, `stats` — JSON `[{ru,en,lv,v}]` ×3, `src_lang` — язык, на котором писали), `card_sets` (названия коллекций), `card_owner` (`card_id` — первичный ключ, второго владельца не бывает).
- **API**: `GET /api/cards?lang=&collection=&rarity=&show=all|free|sold|mine&owner=ник&order=album`; `POST /api/cards/buy {id, price}` — одна транзакция: карточка свободна и не скрыта, пуговок хватает, цена та же (иначе `409 price` с новой ценой), лимит «в одни руки в первые сутки» (`RULES.cardsFirstDay`, сутки — с первой карточки коллекции). Журнал пуговок — `kind = 'card'`. После покупки — `flockEvent('card', птичка, данные)` (пока пустая).
- **Цена обычной** = средняя «цена сейчас» обычной вещи в продаже (без легендарных и сюрпризов) × `RULES.cardMult` % (по умолчанию 100), до 5. Редкие и уникальные — `cards.price`.
- **Перевод** — одна функция `worker/translate.js` (`translateAll`, `translateTo`; из blog.js перенесена туда, блог и «Нарисуй мне» берут её же). Кнопка кабинета — `site/assets/translate-btn.js` (`PPTranslateBtn`), сервер `POST /api/admin/translate {texts, from, to, about}`.
- **Кабинет** → 🛍 Магазин и игры → 🃏 Карточки (`site/assets/cards-admin.js`): список, «＋ Новая карточка» (номер — следующий), правка всего, «Сменить номер» (занят — меняются), скрыть, удалить (только без владельца), загрузка картинки → R2 `cards/`, множитель цены обычных, «⟳ Импортировать карточки с сайта», «🌐 Перевести недостающее». Лимит в одни руки — 📜 Все правила → Магазин.
- **Импорт из репозитория**: `site/assets/cards/<коллекция>.json` — список `{n, lang, rarity, collection, title, desc, stats: [{name, v}], img}`; `index.json` рядом собирает build.py. Каждая коллекция заносится один раз (метка `meta cards_<коллекция>`), недостающие языки переводит Gemini; занятый номер — следующий свободный. Запускается кнопкой и каждый час по расписанию.
- **Витрина** — `site/assets/cards-ui.js` (`PPCards.card / tile / open / buy / mount`): раздел в магазине (`#cards` в src/pages/shop.html), его же возьмёт альбом (этап 7). Стили `.pc-*` в style.css.
- **Копии и данные**: полная копия сайта — `cards` (карточки, коллекции, владельцы) + картинки R2 `cards/`; «Мои данные» (`/api/export`) — карточки птички; удаление аккаунта освобождает карточки, блокировка не трогает.
- Картинки «Хеллоуин 2026» рисует `tools/cards/halloween.py` (Pillow) → `site/images/cards/halloween-2026/NN.png`.
- Этап 6: в магазине «Карточки» — вкладка общего каталога (catalog-ui.js → `PPCards.mount`); новая коллекция — строкой в «Новое в магазине» (GET /api/new → `cards`). Гостю — «Вылупи птичку, чтобы покупать».
