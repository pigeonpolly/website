# Кабинет админа

`/admin/` — `src/pages/admin.html` + `site/assets/admin.js` (стили `.adm-*` в `site/assets/style.css`). Видит только админ (с PIN, см. «🔐 Защита»).

## Как устроено

- **Разделы — один список `ADMIN_SECTIONS`** в начале `admin.js`: `{ id, ic (значок), name, group, about, open?, href?, focus?, count? }`. Меню строится из него, группы — `ADMIN_GROUPS`. Новый раздел = одна строка списка (+ функция экрана в `SECTIONS`, если экран новый).
  - `open` — показать экран другого раздела (например, «Подарки и зарплата» = экран «Все птицы»);
  - `href` — раздел живёт на своей странице (Блог, Нарисуй мне, Ключ Gemini), в меню со стрелкой ↗;
  - `focus` — к чему прокрутить экран (свёрнутое раскроется, место мигнёт);
  - `about` — строка «что здесь делается» над экраном;
  - `count` — красный счётчик в меню (из `/api/admin/inbox`).
- Первый экран — **📥 Входящие** (`/admin/` или `/admin/#inbox`; старый `#overview` ведёт туда же). Только то, что ждёт Алину: комментарии на проверке, заявки «Нарисуй мне», новые подписчики, красные пункты автопилота, пустые окошки адвента (с октября), правки сайта поверх кода, запланированные статьи. Пусто — «Всё спокойно ✓». Ниже свёрнута «📊 Статистика сайта» (прежний «Обзор»).
  - API: `GET /api/admin/inbox` (worker/index.js). «Новые подписчики» — после `meta.inbox_subs_seen`; открыть раздел «Подписчики» = посмотрела (`POST /api/admin/inbox/seen {k:'subs'}`).
- Каждый экран: строка «что здесь делается» → главная кнопка сверху → тонкая настройка свёрнута (`details.adm-fine`) → опасное внизу в красной рамке (`.adm-danger`: Опустошить полки, Восстановить из копии, Вернуть правила по умолчанию, Убрать PIN).
- **Админ-полоска** на каждой странице сайта (в полоске цифр над шапкой, `account.js` → `adminStrip()`): «✏️ Править страницу» (если на странице есть блоки `data-ppb`) и «⚙ В кабинете: …» — магазин → Магазин, галереи и палитры → Картины, статья → редактор этой статьи, челлендж → Челлендж, адвент → Адвент, стая → Стая, игры → Награды игр, профиль птички → Все птицы, остальное → Входящие.

## Меню

| Группа | Раздел | Где |
|---|---|---|
| — | 📥 Входящие | `#inbox` |
| ✍️ Публиковать | Блог · Нарисуй мне · Картины и палитры · Правки страниц | `/blog-editor/` · `/ru/requests/` · `#art` · `#edits` |
| 🐦 Птицы | Все птицы · Подарки и зарплата · Комментарии · Подписчики | `#birds` · `#gifts` · `#comments` · `#subscribers` |
| 🛍 Магазин и игры | Магазин · Адвент · Награды игр | `#shop` · `#advent` · `#games` |
| 📊 Статистика | Посетители · Статьи · Челлендж · Стая | `#visitors` · `#analytics` · `#challenge` · `#flock` |
| ⚙️ Сервис | Копии · Все правила · Ключ Gemini · Строгий режим · Защита | `#backup` · `#rules` · `/blog-editor/#gemini` · `#strict` · `#security` |

## Хочу сделать X → где это

| Хочу… | Где |
|---|---|
| Посмотреть, что ждёт меня сегодня | Кабинет → 📥 Входящие |
| Написать или поправить статью | ✍️ Публиковать → Блог (или «⚙ В кабинете: редактор этой статьи» на странице статьи) |
| Опубликовать черновик сейчас | Редактор статьи → «Опубликовать сейчас» |
| Запланировать статью на потом | Редактор → ⚙ Настройки → дата и время в будущем → «⏰ Запланировать на …» |
| Выпустить застрявшие запланированные статьи | Блог → над списком «N статей ждут публикации · Опубликовать сейчас» |
| Одобрить или удалить комментарий со ссылкой | Входящие → «комментарии ждут проверки» или 🐦 Птицы → Комментарии |
| Включить строгий режим комментариев | ⚙️ Сервис → Строгий режим |
| Ответить на заявку «Нарисуй мне», поставить приём на паузу | ✍️ Публиковать → Нарисуй мне (страница `/requests/`, кнопки видны только админу) |
| Добавить картину или палитру, скрыть картину | Страница галереи или палитр (кнопки видны только админу); сводка — Картины и палитры |
| Поменять текст или скрыть блок на странице | На странице: «✏️ Править страницу» в админ-полоске |
| Вернуть блок как было | ✍️ Публиковать → Правки страниц |
| Подарить вещь птичке или всем, выдать зарплату | 🐦 Птицы → Подарки и зарплата |
| Добавить или забрать пуговки у птички | 🐦 Птицы → Все птицы → «±» в строке |
| Скачать адреса подписчиков | 🐦 Птицы → Подписчики |
| Пополнить магазин | 🛍 Магазин → «Пополнить» (сверху) |
| Поменять цены категорий и легендарных | 🛍 Магазин → «⚙️ Тонкая настройка цен» |
| Убрать всё из продажи | 🛍 Магазин → внизу, красная рамка → «Опустошить полки» |
| Положить вещи в окошки адвента | 🛍 Магазин и игры → Адвент |
| Поменять награды игр | 🛍 Магазин и игры → Награды игр |
| Узнать, сколько людей заходит и откуда; сделать ссылку с меткой | 📊 Статистика → Посетители |
| Посмотреть популярные статьи | 📊 Статистика → Статьи |
| Посмотреть новые работы челленджа | 📊 Статистика → Челлендж |
| Посмотреть новых птиц | 📊 Статистика → Стая |
| Скачать копию сайта, настроить автокопию | ⚙️ Сервис → Копии |
| Восстановить сайт из копии | ⚙️ Сервис → Копии → внизу, красная рамка |
| Проверить, что всё работает само; поменять правила | ⚙️ Сервис → Все правила (автопилот сверху, тонкая настройка свёрнута) |
| Вставить ключ Gemini для перевода | ⚙️ Сервис → Ключ Gemini |
| Задать PIN, сделать код восстановления | ⚙️ Сервис → Защита |
| Карусели для соцсетей | Страница челленджа → «📸 Карусели» |
