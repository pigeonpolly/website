# Челлендж: подбор тем, редактор месяца, бейдж «Три в одном»

## ТЗ (этап 3, до 1.11.2026)

Проблема: в одном месяце выпали «корзина яблок» и «яблоко», а добавление предметов сдвигает темы. Решение: алгоритм предлагает план месяца, Алина правит.

1. **Разметка 1080 предметов** → `content/challenge-tags.json` (по индексу предмета; порядок `challenge-data.js` не трогать):
   семья (главное существительное; ёмкости basket/bowl/cup/jar/box/bag/plate/slice/piece/bunch/pile/stack/pair/bottle/glass/set отбрасываются; после «of» — то, что после; блюдо из одного продукта → продукт; ед. число), категория (food, drink, animal, bird, plant, home, clothes, transport, place, nature, weather, tool, toy, music, fantasy, person, holiday), сложность (1 — один простой предмет; 2 — с деталями или 2–3 предмета; 3 — сцена, место, персонаж в действии).
2. **Генератор** `worker/challenge-plan.js`: семья не ближе 90 дней и никогда дважды в месяце; категория не два дня подряд, в любые 7 дней ≥ 5 разных; сложность «колодой» на 7 дней: 3 простых, 3 средних, 1 сложная; сезон 2/3, 23 января и ЭКСТРА — как сейчас. Все числа — в «📜 Правилах». `build.py` пишет `site/assets/challenge-items.json` (предметы + теги) для worker.
3. **План месяца в D1** — `challenge_days` (day, item, subject en/ru/lv, tip en/ru/lv, colors, time, twist en/ru/lv, extra en/ru/lv, edited, updated_at). Cron 20-го создаёт следующий месяц; созданный месяц сам не меняется. Октябрь 2026 — `tools/challenge_oct.js` считает текущим `themeFor` → `site/assets/challenge-2026-10.json`, worker импортирует один раз. Ноябрь — по новым правилам.
4. **Клиент:** `GET /api/challenge/month?m=YYYY-MM`, ответ кэшируется в localStorage; нет ответа и кэша → «тема загружается…» (старую формулу для дней с ноября не использовать).
5. **Всё, что зависит от темы дня, читает план:** challenge.js, today.js, календарь, карточка «поделиться», сервер (DAYCOL, extraDay, серии). `tools/daycolors.js` — только дни до 1.11.2026. Выданные бейджи не отнимаются.
6. **Кабинет → «🎨 Темы челленджа»** (ADMIN_SECTIONS, группа «✍️ Публиковать»; админ-полоска на /challenge/ ведёт сюда): календарь текущего и следующего месяца, «В цвете / Ч/Б»; окно дня — предмет, совет, 3 цвета (из 10 базовых), время, Ч/Б-особенность (EN/RU/LV), в день ЭКСТРА — палитра и Ч/Б-условие; кнопки «🌐 Перевести», «🎲 Другой предмет», «⇄ Поменять с днём…», «↩ Вернуть как было»; правленые дни — ✏️; прошедший день с работами — «уже N работ, у них тема поменяется».
7. **`tools/challenge_check.js`** — симуляция 24 месяцев тем же модулем, текстом только нарушения и итог.
8. **Бейдж «Три в одном»** (`triple`, 15 🔘): за один день по Риге загрузить работы за позавчера, вчера и сегодня. Описание: «Позавчера, вчера и сегодня — за один вечер. Время — всего лишь условность.» Как получить: «Загрузить за один день работы за позавчера, вчера и сегодня». 3 языка; картинка — Полли с тремя листками.

Готово, когда: `challenge_check.js` — 0 нарушений; октябрь на сайте не изменился; ноябрь читается из базы; правка дня в кабинете видна на /challenge/.
Не трогать: прошлые бейджи, порядок `challenge-data.js`.

## Как устроено

### Разметка (часть 1)
- `tools/challenge_tags.js` (node) → `content/challenge-tags.json`: массив `{i, en, f, c, d}` по индексу предмета (`i`), `en` — для сверки.
- Сначала правила в скрипте (семья, словарь ключевых слов `KW` для категорий, сложность: place/nature/«scene»/«with» → 3, «of»/«and» → 2, иначе 1), поверх — ручные правки `content/challenge-tags-fixes.txt`, строки `индекс=значение`: `1|2|3` — сложность, имя категории — категория, иначе (или `f:слово`) — семья. Последняя правка поля побеждает.
- Команды: `node tools/challenge_tags.js` — пересобрать; `groups N` — пачка N семей, где больше одного предмета; `uncat N` — предметы без категории по словарю; `apply < правки` — дописать правки и пересобрать.
- Новые предметы (дописываются в конец `challenge-data.js`): запустить скрипт, проверить их строки, при необходимости дописать правки.
- Итог разметки (16.10.2026): 865 семей, сложность 1/2/3 = 811/153/116.
