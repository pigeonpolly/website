# Убранное: от чего отказались

## Кратко
- Реестр отказов. Алина отказалась от механики/блока → строка в «Ждёт чистки». Claude удаляет хвосты (код, предупреждения, тексты на 3 языках, docs) и переносит строку в «Убрано».
- Колонка «Маркер» — строка, которой в живом коде больше быть не должно (имя файла, переменная, адрес). `python3 tools/dead_check.py` проверяет маркеры раздела «Убрано» (код выхода 1 — убранное вернулось) и сам ищет сирот: несобираемые страницы, блоки без страницы, файлы site/assets без ссылок, адреса /api без вызова.
- Данные в D1/R2 (таблицы, поля, старые записи) не удаляем без отдельного «да» Алины — пишем «данные остаются».
- Подробная история решений — docs/history.md; здесь — только что убрано и где могли остаться хвосты.
