- 0-1 = перенос старого CLAUDE.md (коммит 63ba1e0).

- i18n_add.py: «встречается в HTML больше одного раза» считается по собранным EN-страницам site/ (без site/ru, site/lv); существующий ключ без --force не переписывается.
- sec.py: заголовок ищется без учёта регистра — точно, по началу, по подстроке.
- 0-2: общий раздел старого CLAUDE.md (устройство, языки, картинки, дизайн, подключено, проверка) вынесен в docs/basics.md, чтобы CLAUDE.md был ≤ 6 КБ; check_split.py ищет опорные куски в CLAUDE.md + basics.md.
- 4 А: вид `reply` пропущен — у комментариев блога нет ответов. Число на 🔔 — сколько карточек в ленте (не сумма n).
- 4: на 360 px у вошедших в шапке остаётся только звёздочка (колокольчик занимает место); с 390 px название видно.
- 4 Б: строка «Адвент» в автопилоте — с 15.11 до 31.12.
