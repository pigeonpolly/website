# Freebies /freebies/ — бесплатное для скачивания

- Страница `src/pages/freebies.html` (шаблон v2, `V2` в build.py), скрипт `site/assets/freebies.js`, стили `site/assets/freebies.css`, данные `site/assets/freebies.json`. В шапке пункт «Freebies / Бесплатно / Bez maksas» стоит на месте «Palettes» (меню не длиннее); палитры — в подвале и карточкой «Open the palettes» внизу раздела.
- Карточки как на /learn/ (.vc, .flt из v2.css): веер из 3 дизайнов, наклейка «Календарь / Весь год / Заставка». Фильтр: Вид (Всё · Календари · Заставки) · Календарь (Месяц и год · На месяц · На год; data-p, при «на месяц/год» заставки скрыты) · Неделя (с понедельника · EU / с воскресенья · US / любая; по умолчанию — по языку браузера: en-US, CA, MX, BR, JP, PH, IL → воскресенье) · Год. Нажатие — окно: превью, выбор из 3 дизайнов, «⬇ Скачать» (полный JPG).
- Ссылка `/freebies/?f=<id>&d=<1–3>` — фильтр под эту вещь, подсветка и сразу окно (сюда ведут пины). id: `2027-01-mon`, `2027-year-sun`, заставка — ключ арта.
- Всё рисует `node tools/pins/cal.js [cal|wall|year|all] [месяц…]`: арты по месяцам — `tools/pins/cal-data.js`, год — `YART` в cal.js. Дизайны: 1 «Ночь» (арт тает в тёмном фоне, клетки), 2 «Бумага» (как пример Алины: лист с зерном, неровный край, Caveat Brush + Patrick Hand), 3 «Арка» (пастель из палитры, арт в арке, выходные — кружки цветов палитры). Цвета — из content/palettes.json. Файлы: `site/images/freebies/cal/<id>-<д>.jpg` 1600×2400 (+ `t/` 480×720), `wall/<key>.jpg` 1179×2556 (+ `t/`). Заставка (Алина 15.11) — только арт на весь экран (кадр `wpos` в cal-data.js, чтобы герой был в кадре) и крошечный белый значок внизу, без рамок и палитры.
- Новые вещи (другой год, новые заставки) — тот же генератор, `YEAR`/`FIRST_PIN`/данные в cal-data.js; freebies.json пишется сам.
