# Freebies /freebies/ — бесплатное для скачивания

- Страница `src/pages/freebies.html` (шаблон v2, `V2` в build.py), скрипт `site/assets/freebies.js`, стили `site/assets/freebies.css`, данные `site/assets/freebies.json`. В шапке пункт «Freebies / Бесплатно / Bez maksas» стоит на месте «Palettes» (меню не длиннее); палитры — в подвале и карточкой «Open the palettes» внизу раздела.
- Карточки как на /learn/ (.vc, .flt из v2.css): веер из 3 дизайнов, наклейка «Календарь / Весь год / Заставка». Фильтр: Вид (Всё · Календари · Заставки) · Календарь (Месяц и год · На месяц · На год; data-p, при «на месяц/год» заставки скрыты) · Неделя (с понедельника · EU / с воскресенья · US; «любая неделя» убрана — Алина: бессмысленно; по умолчанию — по языку браузера: en-US, CA, MX, BR, JP, PH, IL → воскресенье) · Год. Выбор вида сбрасывает остальные фильтры; фильтр календаря при «Заставках» переключает на «Календари»; «✕ Сбросить фильтры» (.fb-rs) — когда что-то выбрано. Нажатие — окно: превью, выбор из 3 дизайнов, «⬇ Скачать» (полный JPG).
- Ссылка `/freebies/?f=<id>&d=<1–3>` — фильтр под эту вещь, подсветка и сразу окно (сюда ведут пины). id: `2027-01-mon`, `2027-year-sun`, заставка — ключ арта.
- Всё рисует `node tools/pins/cal.js [cal|wall|year|all] [месяц…]`: арты по месяцам — `tools/pins/cal-data.js`, год — `YART` в cal.js. Дизайны: 1 «Ночь» (арт тает в тёмном фоне, клетки), 2 «Бумага» (как пример Алины: лист с зерном, неровный край, Caveat Brush + Patrick Hand), 3 «Арка» (пастель из палитры, арт в арке, выходные — кружки цветов палитры). Цвета — из content/palettes.json. Файлы: `site/images/freebies/cal/<id>-<д>.jpg` 1600×2400 (+ `t/` 480×720), `wall/<key>.jpg` 1179×2556 (+ `t/`). Заставки — свой список `walls` в cal-data.js (не арты календарей; фото работ из photos2/ без палитры — цвета сайта). Заставка (Алина 15.11) — только арт на весь экран (кадр `wpos` в cal-data.js, чтобы герой был в кадре) и крошечный белый значок внизу, без рамок и палитры.
- Новые вещи (другой год, новые заставки) — тот же генератор, `YEAR`/`FIRST_PIN`/данные в cal-data.js; freebies.json пишется сам.
- Notion «Pinterest pins 3.0»: у пинов календарей своя «Актуальность» с годом — «Зима 2027» (январь, февраль и декабрь), «Весна 2027», «Лето 2027», «Осень 2027», «Весь 2027» (календари на год); вид-доска «📅 2027 по сезонам». Общие «Зима/Весна…/Круглый год» — только для вечных пинов. cal.js пишет так сам (`${season} ${YEAR}`).
- Доп. календари вне `YEAR` — список `extra` в cal-data.js (`y`, `m`, `v` — буква второго арта месяца, `first` — первый номер пина, `ds` — какие дизайны, `titles` — свои заголовки пинов); рисует `node tools/pins/cal.js extra`. Декабрь 2026 (Алина 15.11): «Новый год в кровати» Полли — 3 дизайна, пины 566–571; Мистер Чу с мешком подарков (`2026-12b`) — дизайны 1–2 (в «Арке» режется надпись арта), пины 572–575; арты не из календарей 2027. Notion: «Зима 2026». На карточке число дизайнов — по факту (`T.d3(n)`).
- 20.11.2026: рядом — страница **/draw/ «Things to draw»** (src/pages/draw.html, site/assets/draw.js + draw.css, данные site/assets/draw.json от tools/pins/pins16.js): полные версии пинов-тизеров №945+ — списки тем (печать), бинго (клетки зачёркиваются, localStorage), палитры с копированием HEX, 4 шага с советом, «найди детали/отличия» с ответами, контуры PNG для скачивания. Фильтр «Вид», ссылка `?f=p<номер>` — сразу окно. В меню Room 511 и подвале — после Freebies; кнопка «Things to draw» в карточке «more» на /freebies/. Печать — только окно (@media print).
