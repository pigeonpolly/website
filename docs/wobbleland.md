## Wobbleland
- Страница `src/pages/wobbleland.html` (+ `.ru.html`, `.lv.html` — длинные тексты Полли), скрипт `site/assets/wobbleland.js`, стили — блок `.wl-*` в `style.css`.
- Данные 11 городов — `content/wobbleland.json` (EN). Переводы — `content/i18n/wobbleland.{ru,lv}.json` (по ключу города, массивы в том же порядке). `build.py` → `site/assets/wobbleland-data.<lang>.js`. Названия городов на всех языках латиницей, кроме Департамента (`name`/`short` переводятся).
- Карта пиксельная: `site/images/wobbleland/map-pixel.png` (1280×928; рельеф считается на 640 и ×2, улицы/дома/значки рисуются по ручной разметке `tools/wobbleland/anno.py` — координаты в пикселях акварели 1280×928, номера домов прочитаны с её карты; генератор `tools/wobbleland/make_map4.py`, исходники акварели (карта, гербы, виды городов, комиксы, исходный виджет) лежат в `tools/wobbleland/source/`). Раньше было 640×464, показывается с `image-rendering: pixelated`). Сгенерирована из акварельной карты Алины скриптом на Pillow (вода по цвету, сглаживание, домики-спрайты 8×8, красная железная дорога). Акварель на сайте не используется — Алина попросила убрать.
- Гербы — пиксельные `crest-<key>.png` (40×46, один щит с золотой каймой), нарисованы вручную по мотивам её акварельных гербов. Департамент — зеркало с хмурым отражением.
- В карточке города вверху — кусок той же пиксельной карты вокруг города (CSS background, `viewPos()` в JS) с мигающей точкой.
- Комиксы и квиз «Из какого вы города» Алина пока НЕ хочет (код квиза в JS остался, но блока на странице нет).
- Слой поверх карты (`content/wobbleland-map.json`, экспорт из anno.py): подписи улиц и площадей (видны при приближении ≥1.8, переводы в `_map` файлов wobbleland.{ru,lv}.json), фигурки персонажей у их домов (`ch-*.png`, `tools/wobbleland/sprites.py`), подсказка «улица + номер + кто живёт/работает» при наведении/тапе на домик.
- Наверху справа — отрывной листок с ближайшим праздником, правее — резной корешок книги рецептов ( (кнопки ‹ Сегодня › листают праздники). Клик по персонажу на карте — облачко с репликой (SAY в wobbleland.js, 3 языка), а не город. Календарь праздников — сетка месяца с гербами в дни праздников + список праздников месяца справа. Ниже карты — книга рецептов (разворот с 3D-перелистыванием, по блюду на разворот, пиксельные картинки `dish-<город>-<i>.png` из `tools/wobbleland/dishes.py`, закладки-города) и календарь праздников (даты из английского `Mar 12` → поля m/d в build.py).
- **Жители из карточек (этап 8)**: `tools/wobbleland/residents.py` — 38 персонажей коллекционных карточек: в `cities[].residents[]` (поля `key`, `home`, `job`, `trait`, `card`) после старых жителей, переводы — те же индексы в wobbleland.{ru,lv}.json, `chars` с `"sm": true` в wobbleland-map.json, медальоны `ch-<key>.png` (20×20) из картинки карточки. Повторный запуск пересобирает только их. Потом `python3 tools/titos_cast.py`.
- В JS: у `sm` медальон меньше (`.wl-char.sm`), клик — облачко с занятием и чертой (вместо SAY); в списке жителей города — занятие и черта.
