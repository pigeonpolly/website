## Палитры из артов
- `tools/palettes.py` (numpy) → `content/palettes.json`: из каждой картинки галерей bird, snail, sketchbook, halloween, detective, anxiety (кроме anxiety-7), challenge — 3 ярких цвета (отдельный k-means по насыщенным пикселям, чтобы маленькие акценты не терялись; слишком сочные приглушаются) + 3 спокойных (по площади, белая бумага не считается). Имена — ближайшее в Lab из `tools/palette_names.py` (en/ru/lv), названия палитр — `tools/palette_titles.py`, ручные палитры (те же, что в пинах) — `tools/palette_overrides.py`. AI-арт не берём. Новая картинка → название в palette_titles.py и перезапуск. Кнопки «Сохранить в Pinterest» на странице нет (Алина убрала).
- `build.py` копирует данные в `site/assets/palettes.json`. Страница `/palettes/` (Books & Helpful → «Палитры», `src/pages/palettes.html`, `site/assets/palettes.js`): фильтр по сериям, 🎲 случайная, клик по цвету — копирует HEX, «Скопировать все HEX», «📌 Сохранить в Pinterest», ссылка `#ключ-картинки` подсвечивает палитру. В челлендже кнопка «🎨 Палитра для вдохновения» (`#ch-pal-btn`) — окно со случайной палитрой.
  - ⚠ Раздела «Books & Helpful» больше нет — «Палитры» в меню «Рисовать», см. docs/site.md.

## Палитра из своего фото
- Вверху страницы «Палитры» (`palettes.js`, `maker()`): посетитель выбирает фото → в браузере считается палитра тем же алгоритмом, что `tools/palettes.py` (3 ярких + 3 спокойных, Lab k-means; `extract()`), названия цветов — ближайшие из `site/assets/palette-names.json` (build.py пишет из `tools/palette_names.py`). Карточка 1000×1500 рисуется на canvas в стиле пинов-палитр (`drawCard()`): фото сверху, «ПАЛИТРА», название (поле ввода; по умолчанию «Моя палитра» или имя файла), 6 плашек с названием и HEX, слева внизу «сделано с Pigeon Polly», справа внизу плашка сайта (пиксельная Полли + pigeonpolly.com). Название по умолчанию берётся из имени файла (если не IMG_/DSC/цифры). Пипетки: под кнопками — фото с 6 кружками там, где взят каждый цвет (`extract()` отдаёт `{hex,u,v}`, u/v — ближайший по цвету пиксель); кружок можно тянуть или выбрать и тапнуть по фото (или стрелками) — цвет усредняется 5×5 из копии фото 800px, название — ближайшее незанятое из словаря (`nameOf`), карточка перерисовывается; «Вернуть как было» — авто-палитра. Кнопка «Скачать карточку» — JPG. Фото на сервер не отправляется. Стили `.pal-mk*` в style.css.
- Палитры: блок «🎨 Палитра из вашего фото» (.pal-mk) — на белом фоне (#FFFDF8, тёмный текст), 12.10.2026.
